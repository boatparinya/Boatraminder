# 🌸 Gigi Reminds Me (Personal Reminder Web App)

ระบบเว็บแอปพลิเคชันแจ้งเตือนและบันทึกกิจกรรมส่วนตัว ดีไซน์สไตล์ Pastel/Minimalist น่ารัก สบายตา และมีประสิทธิภาพสำหรับเตง (Parinya) ออกแบบและดูแลโดย Gigi เลขาส่วนตัวค่ะ 💕

---

## 🚀 วิธีการเปิดใช้งาน (How to Run)

เตงสามารถเริ่มเปิดใช้งานโปรแกรมได้ง่ายๆ ตามขั้นตอนนี้ค่ะ:

1. **เปิด Terminal / PowerShell** ในโฟลเดอร์โครงการนี้
2. **รันคำสั่งด้านล่างนี้เพื่อเปิดเซิร์ฟเวอร์หลังบ้าน:**
   ```bash
   npm start
   ```
   *(หรือถ้าต้องการรันโหมดพัฒนาสำหรับอัปเดตไฟล์แบบ auto-restart ให้รัน `npm run dev` ค่ะ)*
   
3. **เปิดบราวเซอร์** แล้วเข้าไปที่ลิงก์นี้ได้ทันทีเลยค่ะเตง:
   👉 **[http://localhost:3000](http://localhost:3000)**

---

## 🎨 โครงสร้างของระบบ (Project Files)

*   `server.js` - เซิร์ฟเวอร์ Express สำหรับประมวลผลดึงข้อมูลและจัดการ CRUD
*   `index.html` - หน้าจอแอปพลิเคชันส่วนตัว ใช้ Tailwind CSS v4 และฟอนต์สุดน่ารัก Mitr + Outfit
*   `app.js` - ส่วนควบคุมหน้าบ้าน คำนวณวัน เวลา แจ้งเตือน Toast และยิงคำทักทายของ Gigi
*   `style.css` - สไตล์เสริม เพิ่มแอนิเมชันตอนเปิดหน้าจอ การเลื่อนของแจ้งเตือน และการขีดฆ่างานที่ทำเสร็จ
*   `data/reminders.json` - ฐานข้อมูลไฟล์เดี่ยวสำหรับเก็บกิจกรรมทั้งหมดของเตงแบบถาวร

---

## ✨ ฟีเจอร์ที่เค้าเตรียมไว้ให้เตง

1.  **Gigi's Time Greetings:** ระบบจะคำนวณเวลาจริงของระบบและแสดงคำทักทายจาก Gigi ตามช่วงเวลา (เช้า/บ่าย/เย็น/ค่ำ) ด้วยความห่วงใยค่ะ
2.  **Countdown Time Tracker:** ตารางกิจกรรมจะบอกเวลาคงเหลือในปัจจุบัน เช่น "อีก 2 ชม.", "พรุ่งนี้", หรือแสดงเตือน "เลยกำหนดแล้วนะเตง! ⚠️" เพื่อไม่ให้เตงลืมส่งการบ้านเภสัชฯ หรือเข้ากิจกรรม
3.  **Category Badges:** แบ่งกลุ่มกิจกรรมด้วยสีพาสเทลน่ารักๆ (การเรียน = สีฟ้า, กิจกรรมคณะ = สีม่วง, ส่วนตัว = สีเขียว)
4.  **Completed Tab History:** สำหรับงานที่ทำเสร็จแล้ว สามารถกดเปลี่ยนสถานะได้ (Mark as Completed) เพื่อสลับแท็บแยกเก็บประวัติงานเป็นระเบียบค่ะ
5.  **Cute Toast Notifications:** แสดงข้อความเตือนเล็กๆ เมื่อเตง เพิ่ม/ลบ/อัปเดตงาน เพื่อสร้างกำลังใจให้ทุกวันค่ะ!
